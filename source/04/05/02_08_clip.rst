切り出し(C)
==============

格子の一部の範囲だけを切り出して、新しい格子として置き換えます。
不要な範囲を取り除きたい時などに利用します。

この機能は、2次元の構造格子に対してのみ利用できます。
非構造格子など、他の種類の格子では使用できません (メニューが選択不可になります)。

切り出しは以下の手順で行います。

#. オブジェクトブラウザーで、切り出しを行う格子（もしくは「格子」の下の「格子形状」）を選択します。
#. 以下のいずれかの操作を行います。

   **メニューバー:** 格子 (G) --> 切り出し (C)...

   **右クリックメニュー:** オブジェクトブラウザーで「格子」の下の「格子形状」を右クリックし、「切り出し (C)...」を選択
   (:numref:`image_grid_clip_menu` 参照)

#. 切り出し設定ダイアログ (:numref:`image_grid_clip_dialog` 参照) が表示されます。
   切り出す範囲を設定します。
#. 「OK」ボタンを押すと、切り出しが実行されます。

.. _image_grid_clip_menu:

.. figure:: images/grid_clip_menu.png
   :width: 160pt

   切り出しのメニュー

切り出し設定ダイアログでは、切り出す範囲を、I 方向と J 方向について、
格子点の番号の最小値と最大値で指定します。
スライダーを動かすか、右側のボックスに値を入力して設定してください。

* I 最小, I 最大: 切り出す範囲の I 方向の最小・最大の格子点番号
* J 最小, J 最大: 切り出す範囲の J 方向の最小・最大の格子点番号

「プレビュー (P)」ボタンを押すと、現在の設定で切り出される範囲が、
描画領域に黒い太線の枠で表示されます。範囲を確認してから「OK」ボタンを押してください。

.. _image_grid_clip_dialog:

.. figure:: images/grid_clip_dialog.png
   :width: 220pt

   切り出し設定ダイアログ

切り出された格子では、格子点の座標、格子点属性、セル属性などの情報は、
切り出された範囲の分だけが引き継がれます。

.. warning::

   切り出しを実行すると、元の格子は切り出し後の格子に置き換えられます。
   この操作を元に戻すことはできません。また、これ以前に行った操作の取り消し (Undo) も
   できなくなります。切り出しを行う前に、プロジェクトを保存しておくことをお勧めします。
