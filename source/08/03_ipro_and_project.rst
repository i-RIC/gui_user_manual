プロジェクトデータの格納先について
=========================================

プロジェクトデータの格納先は、iRICでの作業フローによって異なります。以下の3つのケースがあります。

* プロジェクトを新規作成した時
* プロジェクトファイル (\*.ipro) を開いた時
* プロジェクトフォルダを開いた時

それぞれについて説明します。

.. _sec_project_data_storage_new:

プロジェクトを新規作成した時
-------------------------------

プロジェクトを新規作成した時、最初にプロジェクトを保存するまでの間は、作業ディレクトリに
作成された一時フォルダの中に格納されます。

その後の処理は、プロジェクトファイル (\*.ipro) に保存した場合とプロジェクトフォルダに保存した場合によって異なります。

プロジェクトファイル (\*.ipro) に保存した場合
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

プロジェクトファイル (\*.ipro) の実体は ZIP ファイルです。そのため、拡張子を \*.ipro から \*.zip に変更すれば、開いて内容を確認することができます。

プロジェクトファイル (\*.ipro) を保存する時は、以下の手順で処理が行われます。

1. 作業ディレクトリに、プロジェクトデータを保存します。
2. 作業ディレクトリに一時ファイルとして、 (ランダムな文字列).zip という名前で ZIPファイルを作成し、その中にプロジェクトデータの内容を格納します。
3. 2. で作成した ZIPファイルを、ユーザが指定したファイル名にリネームします。

.. note:: プロジェクトファイル (\*.ipro) に格納される情報

   上記において、 2. では、以下のファイルのみを ZIP ファイルに格納します。

   * iRIC GUI が作業ディレクトリに保存したメタデータと実データ
   * iRIC GUI以外により、作業ディレクトリの直下に保存されたファイル

   上記処理により、プロジェクトファイル (\*.ipro) ファイルに保存した場合、iRIC GUI 以外により作業ディレクトリのサブフォルダ内に保存されたファイルは失われますのでご注意ください。

   iRIC GUI 以外で作成したファイルをサブフォルダ内に保存したい場合は、プロジェクトフォルダに保存するようにしてください。

プロジェクトフォルダに保存した場合
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

プロジェクトフォルダに保存する時は、以下の手順で処理が行われます。

1. 作業ディレクトリに、プロジェクトデータを保存します。
2. 作業ディレクトリを、ユーザが指定したファイル名にリネームします (保存先のプロジェクトフォルダが、作業ディレクトリと別のドライブにある場合は、コピーした後に作業ディレクトリを削除します)。

.. _sec_project_data_storage_ipro:

プロジェクトファイル (\*.ipro) を開いた時
-------------------------------------------------

プロジェクトファイル (\*.ipro) を開いた時は、プロジェクトファイル (\*.ipro) の内容が、作業ディレクトリに
作成された一時フォルダの中に展開されて格納され、読み込まれます。

そこから先の処理は、 :ref:`sec_project_data_storage_new` と同じになります。

.. _sec_project_data_storage_folder:

プロジェクトフォルダを開いた時
-------------------------------------------------

プロジェクトフォルダをを開いた時は、プロジェクトフォルダがそのまま作業ディレクトリとして使用されます。プロジェクトフォルダにあるファイルが読み込まれます。

地理情報をインポートしたり削除したりした時は、このフォルダのファイルが保存されたり削除されたりします。

そのため、:ref:`sec_data_incompatibility` に示した通り、プロジェクトデータの不整合が生じることを防ぐため、プロジェクトフォルダを開いた
時は、プロジェクトを閉じる際、必ず保存が行われます。

.. note::

   かつては、プロジェクトフォルダを開いた時、プロジェクトフォルダの内容を、プロジェクトファイル (\*.ipro) を開いた時と同様、
   作業ディレクトリに作成された一時フォルダの中に展開されて格納するというオプションがありました。現在はそのオプションは廃止されています。
